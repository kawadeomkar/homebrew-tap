# Kawadeomkar Tap

## How do I install these formulae?

`brew install kawadeomkar/tap/<formula>`

Or `brew tap kawadeomkar/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "kawadeomkar/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
